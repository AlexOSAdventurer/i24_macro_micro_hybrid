# Reinforcement learning for the hero-vehicle controllers (sim_rl_sumo_*.py).
# gymnasium is the maintained successor to gym; stable-baselines3 2.9 is the
# first line that accepts gymnasium 1.x and torch 2.11 without pinning either
# back. sb3-contrib supplies RecurrentPPO, the default trainer: the hero's
# observation is a partial view of the bubble, so a memoryless policy is
# optimising over a strictly weaker class than a recurrent one (keep its version
# in lockstep with stable-baselines3). tensorboard is optional at runtime --
# training falls back to the CSV logger without it -- but it is what
# --tensorboard writes to.
